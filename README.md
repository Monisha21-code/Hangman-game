

## About the Project

This is a text-based Hangman game developed using Python
as part of my CodeAlpha Python Developer Internship.

## Features

- Random word selection
- Programming, Animals and Fruits categories
- Hint system
- Six wrong attempts
- Score system
- Guessed letter tracking
- Play again option
- Custom Hangman drawing

## Technologies Used

- Python
- Google Colab

## How to Run

Run the Python file in Google Colab or any Python environment.
